# What is H2O-3 Enterprise?

:::note Placeholder
This is a placeholder page for the H2O-3 Enterprise documentation shell. Content
migration from the existing Sphinx user guide is in progress.
:::

H2O-3 Enterprise is the commercially supported edition of H2O-3, H2O.ai's
open-source, distributed, in-memory machine learning platform. It adds
enterprise capabilities such as vulnerability patching, compliance (SOC 2,
ISO), and the supported scoring runtime.
